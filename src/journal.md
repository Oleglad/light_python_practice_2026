Этап 1. Каркас: Создал минимальный запускаемый скрипт, который запрашивает у пользователя путь к папке и проверяет, существует ли она. Никакого обхода файлов ещё нет — только вход и базовая валидация. Программа запускается, принимает путь к папке и корректно реагирует на существующий/несуществующий путь.

Этап 2. Сканирование: Добавил рекурсивный обход папки. Теперь программа не просто проверяет путь, а собирает метаданные всех файлов: путь, относительный путь, размер, дату изменения, создания и последнего доступа. Обход папок работает, список файлов выводится, метаданные собираются.
Что добавил:
импорт datetime;
функцию scan_directory_recursive(current_path, folder_path);
функцию scan_folder(folder_path);
рекурсивный обход через os.listdir();
разделение элементов на папки и файлы через os.path.isdir() и os.path.isfile();
сбор stat_info = os.stat(item_path);
формирование словаря metadata с полями:
path,
rel_path,
size,
size_mb,
modified,
created,
accessed;
подсчёт общего размера и количества файлов;
вывод статистики и полного списка файлов.

Этап 3. Дубликаты: Добавил вычисление SHA-256 для каждого файла и поиск дубликатов. Результаты хранятся в памяти текущего запуска в виде словаря хэш -> список путей. Также добавил сохранение отчёта в файл и группировку по расширениям. Для файлов считается хэш содержимого, в отчёте выводятся группы из двух и более файлов с одинаковым хэшем.
Что добавил:
импорт hashlib;
импорт defaultdict из collections;
словарь hash_to_paths = defaultdict(list);
функцию calculate_file_hash(file_path, chunk_size=8192);
чтение файла частями через iter(lambda: f.read(chunk_size), b"");
обновление hash_to_paths[file_hash].append(item_path);
пропуск больших файлов > 1 ГБ с пометкой SKIPPED_LARGE_FILE;
обработку ошибок хэширования с пометкой HASH_ERROR;
функцию find_duplicates(hash_to_paths);
вывод групп дубликатов, где 2 и более файла;
вывод полного списка файлов уже с хэшами;
группировку по расширениям;
сохранение отчёта в report_YYYYMMDD_HHMMSS.txt;

подсчёт total_hashed и hash_errors.
